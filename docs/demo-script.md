# Three-minute demo script

1. Generate a new synthetic batch and show the deterministic event IDs.
2. Run the pipeline twice to explain idempotency, deduplication and the quality metrics.
3. Open the dashboard and point to input rows, dropped rows, null rate and gold aggregates.
4. Open `tests/test_pipeline.py`, the CI workflow and the Terraform reference.
5. Close with the production mapping: object storage, Spark, warehouse, orchestration and monitoring.
